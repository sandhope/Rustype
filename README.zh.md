轻量化高性能 Markdown 桌面编辑器

## 项目背景

marktext 拥有业界优秀的 Markdown 实时编辑体验。本项目借鉴 marktext 成熟完善的 Markdown 交互逻辑与编辑能力，以其完善的编辑能力作为功能基准，完成全栈技术架构重构，同时对整体用户体验进行全新独立设计。

## 技术栈

- Tauri
- React
